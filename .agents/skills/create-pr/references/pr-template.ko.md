# 한국어 PR 템플릿

한국어 중심 프로젝트의 기여에 사용한다. 저장소의 필수 PR 양식이 있으면 우선 적용한다. 아래 Markdown을 채우고 안내 주석과 내용이 없는 선택 섹션을 제거한다.

```markdown
## 요약
<!-- 해결한 구체적인 문제와 변경 후 동작을 설명한다. 필요하면 변경 전후 예시를 덧붙인다. -->

## 변경사항
<!-- 최종 diff를 검토하는 데 필요한 내용만 적는다. 요약으로 충분하면 이 섹션을 제거한다. -->

## 검증
<!-- 실제 수행한 검증의 정확한 명령과 결과를 적는다. 실패·미실행 항목과 이유를 명시한다. 모킹 테스트를 실제 외부 서비스 검증으로 표현하지 않는다. -->

## 참고사항
<!-- 선택: 주요 위험, 호환성·마이그레이션, UI 스크린샷, 확인된 관련 이슈. 불필요하면 제거한다. 이슈 번호를 추측하거나 권한 없이 자동 종료 구문을 추가하지 않는다. -->
```

제목과 본문은 한국어로 작성한다. 명령·식별자·경로·저장소의 고정 양식 제목은 원문을 유지한다. 작은 PR은 요약과 검증만으로 간결하게 작성할 수 있다.
