# English PR template

Use for English-language contributions to international or overseas open-source projects. Follow required repository templates first. Fill the Markdown below; remove instructional comments and optional sections without relevant content.

```markdown
## Summary
<!-- State the concrete problem and resulting behavior. Add a before/after example when useful. -->

## Changes
<!-- List only details a reviewer needs to assess the final diff. Remove this section if Summary is sufficient. -->

## Validation
<!-- List checks actually performed, exact commands, and results. State failures or checks not run with reasons. Do not imply mocked tests validate live services. -->

## Notes
<!-- Optional: material risks, compatibility or migration details, UI screenshots, and verified related issues. Remove if unnecessary. Do not invent issue numbers or add automatic closing keywords without authorization. -->
```

Write the title and body in English. Keep command names, identifiers, paths, and required repository headings unchanged. Match detail to the change; a small PR may need only Summary and Validation.
